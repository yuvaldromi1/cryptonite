Cryptonite

About the Project

Cryptonite is a real-time cryptocurrency tracking web application built as part of a Full Stack Developer course. The platform enables users to monitor cryptocurrency prices, view live market data, and manage a personalized watchlist of up to 5 cryptocurrencies.

The application fetches real-time data from the CoinGecko API, providing accurate and up-to-date information about cryptocurrency prices in multiple currencies (USD, EUR, ILS) and market trends.

Key Features

  • 🌐 Real-Time Market Data — Live prices for 250+ cryptocurrencies
  • ⭐ Watchlist Management — Save up to 5 coins for tracking
  • 📊 Live Reports Dashboard — Dynamic charts with real-time updates
  • 🔍 Advanced Search — Find coins by name or symbol
  • 💾 Local Storage — Persistent watchlist data
  • 🌙 Dark Mode Support — Automatic light/dark theme
  • 📱 Responsive Design — Works on all devices

Technologies Used

  • HTML5 — Semantic markup and structure
  • CSS3 — Modern styling with CSS Grid, Flexbox, and animations
  • JavaScript (ES6+) — Asynchronous programming, IIFE pattern, closures
  • AJAX/Fetch API — Asynchronous HTTP requests
  • Chart.js — Interactive data visualization
  • CoinGecko API — Real-time cryptocurrency market data
  • LocalStorage API — Client-side data persistence

Development Patterns

  • ✓ IIFE (Immediately Invoked Function Expression) — Scope encapsulation
  • ✓ Asynchronous Programming — Promises, async/await
  • ✓ DHTML — Dynamic DOM manipulation
  • ✓ Caching Strategy — Efficient API call management
  • ✓ Error Handling — Try-catch blocks and user feedback
  • ✓ Responsive Design — Mobile-first CSS approach
